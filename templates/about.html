WHAT IS IT?

Turning Images Into Meaningful Words

Creating the perfect caption can sometimes take more time than creating the post itself. This project solves that problem by using Artificial Intelligence to analyze an uploaded image and generate suitable captions.

Users can select their preferred social media platform, caption style and caption length. The system then generates multiple caption suggestions along with relevant hashtags and emojis.
